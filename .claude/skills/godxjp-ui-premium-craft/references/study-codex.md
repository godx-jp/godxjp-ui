# Premium UI study — Codex

The useful lessons are **clearer grouping, visible selection, explicit quantities, easier correction, and feedback tied to real state**. Most gradients, glows, floating surfaces, and animated transforms should be rejected. Godx already implements much of the useful behavior; its highest-value opportunities are in keyboard completion, focus continuity, truthful feedback, and consistent composition.

I read all **75 local HTML/CSS/JS files, totaling 12,590 lines, across all 27 source folders**, including inline scripts and `basic-script.js`. I read the corresponding Godx implementations and the required UX skill first. This was a static, read-only study: no edits, installs, builds, tests, or browsers.

Eight folders contain only a premium implementation: Date Range, Gallery, MultiSelect, Navigation, Search, Time Picker, Vertical Image Accordion, and password. Their entries identify useful techniques, not an invented basic-to-premium delta. Some paired examples contain fewer than three independent VALUE improvements.

**Evidence notation**

- Each linked component name opens its source `index.html`. References to `index.html`, `style.css`, and `script.js` in that row belong to that folder.
- `G/` means `/Users/satoshi01/Herd/godxjp-ui/src/components/`.
- Later references such as `Table/style.css:397` use the component names from the table.
- **VALUE** means a useful technique, not an endorsement of the demo’s implementation.
- **DECORATION** adds little task value. **HARMFUL** impairs operation, comprehension, accessibility, or conflicts with Godx’s explicit design constraints.
- “Yes” means the cited implementation provides the technique; it does **not** mean runtime accessibility has been certified.

The translation boundary is explicit in the [required UX skill](/Users/satoshi01/Herd/godxjp-ui/.claude/skills/godxjp-ui-best-ux/SKILL.md:20): semantic tokens; restrained chroma; 400/500/700 weights; 1px card borders; no resting shadows; consistent density; factual localized copy. Default motion is none; meaningful feedback may use approximately **120–200ms, ease-out, and reduced-motion handling** (`SKILL.md:57–72`). The existing 20/18/14/13 type scale and 4px spacing grid provide the hierarchy (`SKILL.md:80–82`).
