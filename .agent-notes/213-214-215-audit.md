## Cross-cutting findings (worth fixing regardless of which issue they land under)

1. **Two conflicting AppShell mobile breakpoints.** `shell-layout.css:395` (900px) and `:1181` (768px) both restructure `.app-root`. The 768px block additionally deletes the footer row and hard-codes `grid-template-rows: 3rem`, silently defeating `--app-shell-bar-height`. Between 768px and 900px the sidebar is hidden by the first rule while the second rule's overrides don't apply — the geometry is incoherent. Almost certainly a merge artifact.
2. **`--overlay-background` is dead.** Documented as the single shared scrim, consumed by nothing.
3. **`AuthFooter` / `AuthIdentity` bypass the prop-vocabulary contract** — local `interface *Props` in the component file instead of a registered type in `src/props/components/layout.prop.ts`. Every other layout export follows the registry. `pnpm check:prop-vocabulary` may or may not catch this; it should.
4. **Frame-coverage evidence infrastructure exists but is empty** (`preview/frame-coverage.ledger.json` → `"components": {}`). Every "1440/1024/390 preview evidence" acceptance criterion across all three issues is therefore unmet *by the repo's own standard*, independent of whether the components work.
